01 — how to get the data
Steps to grab the JSON from Facebook:
1. Open the Facebook video / reel in your browser.
2. Press F12 → go to Network tab → filter by XHR or search video.
3. Alternatively go to Sources / Debugger tab and search Ctrl+F for base_url.
4. Or right-click page → View Page Source, then Ctrl+F → search representations.
5. Copy the entire JSON block (or the full page source) and paste it below.
