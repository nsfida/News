APEX
Market Intelligence Terminal · v1.0.0 · Static Edition

Purpose

APEX is a fully client-side market intelligence dashboard that combines technical analysis, news sentiment, and composite scoring to generate probabilistic decision-support signals for stocks and cryptocurrencies. It runs entirely in your browser — no backend, no server, no login required.

How It Works

  • Fetches or loads market data from JSON datasets (local or API-fed)
  • Computes technical indicators: MA, RSI, MACD, momentum, volatility
  • Scores news sentiment using keyword/pattern analysis
  • Blends all signals into a composite confidence score
  • Produces scenario-based predictions with entry/target/stop zones
  • Caches session data in browser storage for offline use

Data Sources

  • CoinGecko public API (crypto prices, market data)
  • Alpha Vantage / Yahoo Finance (stocks, if API key provided)
  • NewsAPI / RSS JSON feeds (headlines)
  • Manual JSON import (full offline mode)

Technical Stack

  • Pure HTML, CSS, Vanilla JavaScript
  • No build step, no framework, no external libraries
  • Deployable on GitHub Pages, Netlify, Vercel, or any static host
  • LocalStorage / SessionStorage for state persistence
